# 03. シンボル設計

## 3.1 設計方針

1. **効果は1文で言い切れること。** 2文必要なシンボルはレア以上に限る。
2. **因果が生活実感で読めること。** 「猫はネズミを獲る」「バケツは雨漏りを受ける」。
   ルールを覚えるのではなく、思い出す形にする。
3. **タグで束ねる。** シンボルは `tags` を持ち、シナジーは個別IDではなく**タグ参照**で書く。
   これによりシンボルを追加してもシナジー網が自動的に広がる。
4. **1シンボル＝1プリミティブ**が原則。複合効果はレア以上の特権。

## 3.2 タグ一覧

| タグ | 意味 | 例 |
| --- | --- | --- |
| `food` | 食べ物 | おにぎり、カップ麺、たまご |
| `resident` | 住人（人） | 学生、おばあちゃん、大家さん |
| `animal` | 動物 | ノラ猫、ネズミ、ニワトリ |
| `appliance` | 電化製品 | 電球、ラジオ、ブラウン管TV |
| `fragile` | 壊れもの | 電球、茶碗、ブラウン管TV |
| `money` | お金 | 十円玉、一万円札、ポチ袋 |
| `junk` | ガラクタ | 空き缶、新聞紙、ダンボール |
| `water` | 水気 | 雨漏り、バケツ、傘 |
| `plant` | 植物 | 植木鉢、朝顔 |

## 3.3 ビルド軸（勝ち筋）

デッキが向かう先を5軸用意する。3択の候補はこの軸を意識して重み付けする。

| 軸 | 勝ち方 | 中核タグ | 弱点 |
| --- | --- | --- | --- |
| **A. 大所帯** | 数で押す。低単価×大量。 | `resident` `junk` | 出現率が薄まり、事故で下振れ |
| **B. 精鋭** | デッキを絞り、高単価を確実に出す。 | `money` `appliance` | 除去コストが重い。立ち上がりが遅い |
| **C. 生態系** | 破壊と生成の連鎖。猫×ネズミ×卵。 | `animal` `food` | 素材を食い潰すと自壊する |
| **D. 積み立て** | 永続カウンタを育てる。長期戦型。 | `plant` `water` | 序盤が極端に弱い。第3期の壁 |
| **E. 一発** | 低確率高倍率。乗算を重ねる。 | `fragile` `money` | 分散が最大。事故死率が高い |

## 3.6 シナジー例（動作確認用のゴールデンケース）

実装時にスナップショットテストで固定する組み合わせ。

1. **猫ネズミ回転**：🐈×3 + 🐁×6 + 🐔 + 🥚 → 猫がネズミを食い、ニワトリが卵を補充し続ける。
   ネズミ供給が切れると崩壊する。C軸の基本形。
2. **雨漏りバケツ**：💧×2 + 🪣×3 → バケツが毎スピン永続成長。第3期まで耐えれば化ける。D軸。
3. **団地の食卓**：🎒👵×多数 + 🍜🍙 + 🎸📻 → 住人の数がそのまま出力。A軸。
4. **割れ物注意**：🍶🍵💡 + 🧹 + 🧧 → 自分で壊して稼ぐ。E軸。
5. **大家さん囲い**：👴 + 低単価シンボル大量 → -5のペナルティを +2×N で踏み倒す。A軸の上位。

## 3.7 拡張余地

- 初期リリースは **40種**。フル版で **90〜100種**を目標。
- タグ参照で書いているので、シンボル追加時に既存シンボルのコード変更は原則不要。
- 「季節シンボル」（正月・夏祭り）を後から追加できるようにデータを分割しておく。
