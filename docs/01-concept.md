# 01. 企画概要

## 1.1 参照ジャンルの定義

参照タイトル：**『幸運の大家様』(Luck be a Landlord)** — TrampolineTales / 2023年正式版。

ジャンルを分解すると以下の3要素の掛け合わせ。

1. **スロットマシン**：レバーを引くと盤面にランダムに絵柄が並び、コインが出る。結果は運。
2. **デッキビルド**：盤面に並ぶ絵柄プールは**プレイヤーが1スピンごとに1枚ずつ選んで育てる**。
   つまり「運の中身」を自分で設計する。
3. **ローグライク（1ラン完結・右肩上がりのプレッシャー）**：
   一定スピンごとに家賃の支払い期限が来る。家賃は指数的に上がる。払えなければその場でラン終了。

このジャンルの快感の正体は **「自分で仕込んだ確率が爆発する瞬間」**。
「たまたま強い」ではなく「強くなるように仕込んだものが、たまたま揃った」という二段構えが気持ちいい。
設計上、ここを最優先で守る。

## 1.2 コンセプト

> **築40年のボロアパートで、スロットを回して家賃を稼ぐ。**
> 絵柄は住人と生活用品。ネコ、ネズミ、雨漏り、ママチャリ、大家さん。
> 生活感のあるガラクタが噛み合って、最後は町内会の龍神が火を噴く。

- 一言：**「昭和レトロなアパートを舞台にした、スロット式デッキビルダー」**
- テーマを和風・生活感に寄せることで、原典（西洋的な記号のごった煮）と絵面から差別化する。
- シンボル同士の関係が**日常の因果**として直感的に読める（ネコはネズミを獲る、雨漏りはバケツに溜まる、
  電球は隣を照らす）。ルール説明を読まなくても半分わかる状態を目指す。

## 1.3 ターゲットとプレイ文脈

| 項目 | 内容 |
| --- | --- |
| 主ターゲット | 20〜40代、Slay the Spire / Balatro / 幸運の大家様 のようなビルド系を触ったことがある層 |
| 副ターゲット | 「なんとなく回すのが気持ちいい」放置・カジュアル層（チュートリアルで拾う） |
| プレイ文脈 | 通勤電車、寝る前、休憩中。**片手・縦持ち・音なし**が成立すること |
| 1セッション | 1ラン 15〜20分。中断・復帰できること（localStorage に自動保存） |
| デバイス | iOS Safari / Android Chrome を第一級。PC ブラウザは縦長枠で表示 |

## 1.4 差別化（原典との違い）

意図的に変える点を明示しておく。「劣化コピー」にしないための軸。

| 軸 | 原典 | 本作 |
| --- | --- | --- |
| 盤面の向き | 5列×4行（横長） | **4列×5行（縦長）** — 縦持ち画面いっぱいに置ける |
| 入力 | PC前提のクリック | 親指ゾーンだけで完結。スピンは画面下部の大ボタン＋スワイプ |
| テンポ | じっくり | 1スピンの演出上限 **1.2秒**、連打で即スキップ、オートスピン搭載 |
| 世界観 | 無国籍な記号の集合 | 昭和アパートという生活文脈。シナジーが直感で読める |
| 導線 | インストール | **URLを開いたら即プレイ**。アカウント不要、保存はローカル |
| 再挑戦性 | ラン毎ランダム | **デイリーシード**（全員同じ並び）でスコア比較する遊びを標準搭載 |

## 1.5 コアループ

```
        ┌─────────────────────────────────────────┐
        │                                         │
        ▼                                         │
  ①スピンする ──▶ ②シンボルが並ぶ ──▶ ③シナジー判定・コイン獲得
        │                                         │
        │                                         ▼
        │                          ④3択からシンボルを1つ盤面に追加
        │                                （見送って +5コインも可）
        │                                         │
        └────────── 期限スピンでなければ ◀─────────┘
                             │
                     期限スピンなら
                             ▼
                   ⑤家賃を支払う（不足＝ラン終了）
                             │
                             ▼
                   ⑥ショップ（余剰コインで買い物）
                     ・アイテム購入（恒久パッシブ）
                     ・シンボル除去（引きを濃くする）
                     ・リロール
                             │
                             ▼
                     次の期へ（全12期でクリア）
```

**ループの中の意思決定は実質2つだけ**にする。「何を足すか」「何を消すか」。
これ以外の要素（アイテム等）は補助に留め、選択の粒度を粗くしない。

## 1.6 遊びの寿命（リプレイ性）

1. **ビルドの多様性**：シンボルは「軸」タグを持ち、軸ごとに勝ち筋が違う（後述の05軸）。
2. **難易度段位**：クリアすると次段位が解放（気楽 / ふつう / 修羅 / 修羅+）。家賃倍率と初期条件が変わる。
3. **デイリーシード**：日替わりで全員同じ乱数。到達期と最終資産をローカル記録。
4. **図鑑**：出会ったシンボルが埋まる。未発見は「？」表示。収集動機。

## 1.7 収益・公開方針（初期案）

- **無料公開・広告なし・課金なし**。個人開発の作品として GitHub Pages か Cloudflare Pages に静的配信。
- サーバー費ゼロを設計制約とする（保存はすべてクライアント、ランキングは将来の任意機能）。
- 将来の拡張余地：Steam 版やネイティブ移植は考えない。ブラウザで完結させる。
