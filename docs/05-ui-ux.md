# 05. UI / UX 設計（スマホ縦持ち）

## 5.1 前提

- 基準端末：**iPhone 幅 390px × 高さ 844px**（CSS px）。
- 高さは `100dvh` を使う（iOS Safari のアドレスバー伸縮対策）。`100vh` は使わない。
- `env(safe-area-inset-bottom)` を下部パディングに必ず加算する。
- **親指到達範囲は画面下 1/3**。主要操作（スピン／3択の決定）はここに置く。
- 上部は情報表示のみ。タップ対象を置かない。

**縦の割り当て（844px の場合）**

| 領域 | 高さ |
| --- | --- |
| セーフエリア上 | 47 |
| ヘッダ（期・家賃・コイン） | 96 |
| 盤面 | 430 |
| 獲得表示 | 56 |
| 操作エリア（スピン＋サブ） | 180 |
| セーフエリア下 | 34 |
| 合計 | 843 |

小さい端末（高さ 667px）では**盤面のマスを縮める**（82 → 64px）。
盤面はアスペクト比 4:5 を保ったまま `min(90vw, 可用高さ*0.8)` で決める。

## 5.3 3択（ボトムシート）

スピン解決後、下から**ボトムシート**がせり上がる。盤面は上半分に残す
（**「今の盤面を見ながら選ぶ」ことがこのゲームの意思決定そのもの**なので、盤面を隠さない）。

```
│   （盤面は上に残る・やや暗く）    │
├──────────────────────────────┤
│  どれを入居させる？             │
│ ┌────────┬────────┬────────┐ │
│ │   🐔   │   🍺   │   🏆   │ │
│ │ ニワトリ│ 缶ビール│優勝カップ│ │
│ │ 3スピン │ 隣の住人│ 隣接の値 │ │
│ │ ごとに🥚│ に +3  │ を ×2   │ │
│ │ ★★☆☆ │ ★★☆☆ │ ★★★☆ │ │
│ └────────┴────────┴────────┘ │
│                              │
│      見送る（+5コイン）        │
└──────────────────────────────┘
```

- カードは**タップで選択確定ではなく、1タップで拡大表示 → もう1タップで確定**。
  誤タップでビルドが壊れる事故を防ぐ（このジャンルでは1枚の誤選択が致命傷になる）。
- 拡大表示中は、**そのシンボルと噛み合う所持シンボルを盤面上でハイライト**する
  （虫めがねアイテム所持時は常時）。初心者がシナジーを発見する主導線。

## 5.4 スピン演出

**合計1.2秒を上限**とする。長い演出はこのジャンルの死因。

| t | 内容 |
| --- | --- |
| 0.00s | スピンボタンが沈む。触覚フィードバック（`navigator.vibrate(10)`） |
| 0.00–0.35s | 各列が上から下へ順にスライドイン（列ごとに 60ms ずらし） |
| 0.35–0.55s | 全マス確定。効果を持つマスが順にポップ（`scale 1 → 1.15 → 1`） |
| 0.55–1.00s | 各マスに獲得値がふわっと浮かび、盤面下の合計へ吸い込まれる |
| 1.00–1.20s | コイン表示がカウントアップ。100超えなら軽く光る |

- **画面のどこかをタップすると演出を即スキップして結果表示**（連打で高速周回できること）。
- **オートスピン**：長押しでON。0.6秒間隔で自動スピン。3択が出たら自動停止。
- `prefers-reduced-motion: reduce` の場合は**スライドを廃し、フェードのみ**（合計0.3秒）。

## 5.5 情報設計の原則

1. **数字は常に見える。** コイン・家賃・残スピンは常時表示。モーダルで隠さない。
2. **「あと何コイン足りないか」を出す。** 家賃バーは残額を赤字で表示（`あと 58`）。
   これがラン中の緊張の源泉。
3. **効果テキストは盤面のマスを長押しで表示。** タップは選択、長押しは説明、で統一。
4. **色に意味を持たせない。** 色覚特性への配慮として、レアリティは★の数と枠線の形で示す。

## 5.7 チュートリアル

チュートリアル専用ステージは作らない。**初回ランに埋め込む**。

| タイミング | 内容 |
| --- | --- |
| 初回スピン前 | 「レバーを引くとコインが出る」だけ。1文 |
| 初回3択 | 「絵柄を増やすと、スロットに並ぶ絵柄が増える」 |
| 隣接シナジー初発火 | 該当2マスを線で結んで「隣どうしで効果が出た」 |
| 初回家賃 | 「4スピンごとに家賃。払えないと終わり」 |
| 初回ショップ | 「絵柄は捨てられる。減らすほど、残りが出やすくなる」← 最重要概念 |

一度に1つ、**吹き出し1文＋該当箇所のハイライト**のみ。全文スキップ可。

## 5.8 アクセシビリティ

- タップ対象は **44×44px 以上**。
- 盤面セルに `aria-label="ノラ猫 2コイン"` を付与。
- `prefers-reduced-motion` 対応（5.4）。
- 音は完全に任意。**無音で情報が欠落しないこと**（SEは演出の補強のみ）。
- 文字サイズは `rem` ベース。端末の文字拡大設定に追従（盤面は絵柄なので影響なし）。

## 5.9 アートディレクション

- **絵柄は絵文字ベースで開始**（開発速度優先、40種を即日用意できる）。
  ただし 04.9 の通り、後から SVG へ差し替えられる抽象を挟む。
- 背景：くすんだ生成り色（畳・砂壁のイメージ）。盤面枠は木製の質感。
- フォント：日本語は端末標準（`system-ui`）。数字だけ等幅にして桁揺れを防ぐ。
- ダークモード対応（`prefers-color-scheme`）。夜に布団の中で遊ぶ想定。
