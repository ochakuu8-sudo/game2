# ラッキーハイツ 202号室（仮）

スマホ縦持ちブラウザで遊ぶ、**スロット × ローグライク・デッキビルド**ゲーム。
『幸運の大家様』(Luck be a Landlord) と同ジャンル。自分でスロットの絵柄（シンボル）を
増やしてシナジーを組み立て、上がり続ける家賃を払い切ることを目指す。

- 1ラン **約15〜20分**（12期 / 114スピン）
- **片手・縦持ち**、タップだけで完結。1画面に収まりページはスクロールしない
- **ビルド不要**。URL を開いたら即プレイ

## 遊ぶ（GitHub Pages）

リポジトリの **Settings → Pages** で、

- **Source**: Deploy from a branch
- **Branch**: `main` / `/ (root)`

を指定して保存するだけで公開される。ビルドも Actions のワークフローも要らない。

公開先: `https://ochakuu8-sudo.github.io/game2/`

数十秒〜数分で反映される。スマホでこの URL を開き、
ブラウザの共有メニューから「ホーム画面に追加」すると、
アドレスバーなしの全画面・縦固定で起動する（`manifest.webmanifest`）。

### Pages 用にしてあること

| 対応 | 理由 |
| --- | --- |
| `.nojekyll` を置いた | Jekyll のビルドを止めて、ファイルをそのまま配信させる |
| パスをすべて相対にした | `/<repo>/` 配下に置かれても壊れないため。実際にサブパス配信で動作確認済み |
| `manifest.webmanifest` の `start_url` / `scope` を `./` に | 同上。ホーム画面から開いても正しい階層で起動する |
| アイコン 192 / 512 / apple-touch を同梱 | ホーム画面追加時の見た目。iOS は `apple-touch-icon.png` を見る |

> リポジトリ名を変えたり独自ドメインを当てたりする場合は、
> `index.html` の `og:image` の絶対 URL だけ書き換えること（それ以外は相対なので影響なし）。

Service Worker は入れていないので、**初回表示にはネットワークが必要**。
一度開いたあとは進行状況が localStorage に入るため、
通信が切れてもそのランは最後まで続けられる。
（完全なオフライン起動は docs/06 の M3 で対応予定）

## ローカルで動かす

ES Modules をそのまま読むので、静的サーバーに置くだけで動く（バンドラ不要）。

```bash
npm run dev     # http://localhost:5173 を開く
```

`file://` では ES Modules が読めないので、必ずサーバー経由で開くこと。

## バランス調整

ブラウザで動いているのと**同じ `src/core` を Node からそのまま import** して、
ヘッドレスで大量に自動プレイする。演出も DOM も通らないので 1ラン 1ms 以下。

```bash
npm run sim                                  # 既定 2000ラン
npm run sim -- --runs=10000 --policy=greedy  # 貪欲AIのみ
```

判定基準は「ランダムAIでは勝てない」かつ「貪欲AIなら3回に1回勝てる」こと。

現在の実測（400ラン・ふつう）:

| ポリシー | クリア率 | 目標 |
| --- | --- | --- |
| random | 2.3% | 3% 未満 |
| greedy | 32.8% | 25〜35% |

敗北の山は第7〜9期。序盤即死でも終盤消化試合でもない状態になっている。

> シンボルの数値を触ったら必ず `npm run sim` を回し、`src/core/rent.js` の家賃を引き直すこと。

## 構成

```
index.html            画面の骨格
styles.css            1画面に収めるレイアウト（盤面はコンテナクエリで自動リサイズ）
manifest.webmanifest  ホーム画面に追加したとき全画面で開くための設定
.nojekyll             GitHub Pages に「Jekyll を通さずそのまま配信」させる印
src/core/             純粋ロジック。DOM にも UI にも依存しない
  rng.js              シード付き乱数（Math.random は使わない）
  board.js            4列×5行の盤面と8方向隣接
  symbols.js          シンボル34種。効果はプリミティブ6種の組み合わせのみ
  items.js            ショップのアイテム7種
  rent.js             家賃テーブル（実測から引いた値）
  engine.js           スピン解決パイプラインとゲーム進行
  save.js             localStorage への保存
src/ui/app.js         core の状態を DOM に写すだけの層
src/ui/sprites.js     自作SVGスプライト42点（未定義IDは絵文字にフォールバック）
src/ui/audio.js       効果音。音声ファイルを持たず Web Audio で合成する
dev/sprites.html      スプライト確認用ページ（明暗背景・縮小サイズ）
sim/run.mjs           ヘッドレス・バランスシミュレータ
```

**`src/core` が UI に依存しないこと**が設計上の一番大事な制約。
これが崩れるとシミュレータが動かなくなり、バランス調整が感覚論に戻る。

## 実装済み / 未実装

実装済み（docs/06 の M0〜M1 相当）:

- 4×5盤面、シード付き抽選、8フェーズの効果解決
- シンボル34種、アイテム7種、ビルド軸5種ぶんのシナジー
- 3択＋見送り、2タップ確定、相性ハイライト
- 家賃12期、ショップ（購入 / 除去の累進コスト / リロール）
- 中断復帰（localStorage）、死因を出すリザルト、難易度3段位
- 逐次加算の演出（どのマスが読み順に稼いだかを、数字ではなくコインが
  飛んで合計へ吸い込まれる動きで表示）
- 効果音（Web Audio 合成・ミュートは localStorage に保存）
- 自作SVGスプライト42点。タップで演出スキップ、高速モード、動きを減らす設定への対応

未実装:

- チュートリアル、Service Worker によるオフライン起動、図鑑
- デイリーシード（`dailySeed()` は実装済み、UI 未接続）
- シンボル 34 → 40種（docs/03 の 🌰どんぐり など未実装ぶん）
