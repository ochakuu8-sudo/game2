# ラッキーハイツ 202号室（仮）

スマホ縦持ちブラウザで遊ぶ、**スロット × ローグライク・デッキビルド**ゲーム。
『幸運の大家様』(Luck be a Landlord) と同ジャンル。自分でスロットの絵柄（シンボル）を
増やしてシナジーを組み立て、じわじわ上がっていく家賃を払い切ることを目指す。

- 1ラン **約15〜20分**（114スピン）
- **片手・縦持ち**、タップだけで完結
- インストール不要のブラウザゲーム（PWA でホーム画面追加も可）
